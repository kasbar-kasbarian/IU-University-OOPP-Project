HABIT TRACKER — PHASE 2 QUICK START

1. Install Python 3.7+.
2. Open a terminal in this project folder.
3. Run: python main.py
4. Choose menu options 1–6.

On the first run, five predefined habits with four weeks of sample data are loaded.
Changes are saved automatically to data/habit_data.json.

Run tests:
  python -m pip install -r requirements.txt
  python -m pytest -q
